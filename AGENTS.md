# IGoNotes — Редактор заметок на Go и Markdown

IGoNotes — это CLI-приложение на Go, которое при запуске поднимает локальный REST-сервер и открывает им же в браузере страничку веб-интерфейс для редактирования и сохранения Markdown-заметок. Проект поддерживает древовидную структуру каталогов (за хранение отвечает бэкенд), редактирование и предварительный просмотр Markdown-заметок с поддержкой современных спецификаций Markdown. Frontend реализован как одностраничное приложение (SPA) на Svelte, которое встраивается в бинарник и отдаётся сервером.

## Особенности (Статус реализации)

- [x] REST-сервер на Go (1.26+)
- [x] Автоматическое кроссплатформенное открытие интерфейса в браузере при запуске (Windows, macOS, Linux), отключаемое флагом `--no-browser`
- [x] Веб-интерфейс с редактором Markdown встроен как embed-контент в приложение на Go
- [x] Для редактирования Markdown используется **CodeMirror 6** + **marked.js** (live preview, автосохранение)
- [x] Древовидное отображение заметок в веб-интерфейсе
- [x] Поддержка создания, переименования и удаления папок и файлов
- [x] Окно поделено на 2 части: слева дерево, справа редактор (с переключением режимов редактирования и превью)
- [x] Полноценная панель инструментов с кнопками форматирования Markdown (в т.ч. таблицы, списки, подчеркивание) и выпадающими списками
- [x] Автодополнение Markdown (слеш-команды `\` и `/`) и автозакрытие скобок
- [x] Интеллектуальное модальное окно вставки ссылок (с автоподхватом выделенного текста)
- [x] Подсветка синтаксиса в блоках кода (как в редакторе, так и в режиме превью) с выбором языка
- [x] Автосохранение (debounce 2 секунды)
- [x] Использование **SQLite** (`modernc.org/sqlite`) для метаданных (структура дерева, теги)
- [x] Файлы Markdown хранятся в файловой системе: `~/.igonotes/bases/<база>/<тема>/notes/...`
- [x] Загрузка и отображение изображений (Paste, Drag & Drop), хранятся в `assets/images/`
- [x] Статус-бар внизу окна с отображением текущей директории базы заметок
- [x] Оформление интерфейса на **Tailwind CSS v4**
- [ ] Настройки программы хранятся в `~/.config` (XDG-совместимо) — *Реализовано API, но пока нет UI мастера*
- [ ] При первом запуске — мастер настройки параметров в веб-интерфейсе
- [ ] Синхронизация с Git через **go-git** (автосинхронизация по расписанию)
- [ ] Сборка бинарников под разные ОС и архитектуры через gitverse.ru

## Технологии

- **Бэкенд**: Go (1.26+) (маршрутизация `net/http`)
- **Фронтенд**: Svelte 5, Vite, **CodeMirror 6**, **marked.js**, **Tailwind CSS v4**
- **База данных**: SQLite (`modernc.org/sqlite`, чистый Go)
- **Git-синхронизация**: `go-git` (без внешних зависимостей)

## Фронтенд: сборка и внедрение

- Фронтенд разрабатывается и собирается с помощью **Vite** в каталог `web/dist/`
- Сборка выполняется перед компиляцией Go с помощью `make all`
- Контент из `web/dist/` внедряется в бинарник через `//go:embed all:dist`

Рекомендуемая команда полной сборки:
```bash
make all
```

Где Makefile содержит разделение:
```makefile
all: ui go

ui:
	cd web && npm install && npm run build

go:
	mkdir -p builds
	go build -o builds/igonotes ./cmd/api/...
```

## Структура данных

```text
~/.igonotes/
└── bases/
    └── <название_базы>/
        ├── <тема_1>/
        │   └── notes/
        │       ├── note1.md
        │       └── subtopic/
        │           └── note2.md
        └── assets/
            └── images/
                └── Paste image 20260714150000.png

~/.config/igonotes/
└── config.json
```

- Конфигурация приложения: `~/.config/igonotes/config.json`
- SQLite с метаданными: `~/.igonotes/metadata.db`

## REST API

| Метод | Путь | Описание |
|:---|:---|:--- |
| GET | `/api/notes` | Получить дерево заметок (JSON) |
| POST | `/api/notes` | Создать заметку или папку |
| GET | `/api/note?id=...` | Получить содержимое заметки по пути |
| DELETE | `/api/note?id=...` | Удалить заметку или папку |
| POST | `/api/save` | Сохранить изменения в заметке |
| PUT | `/api/rename` | Переименовать файл или папку |
| POST | `/api/sync` | Принудительно синхронизировать ФС и БД |
| GET | `/api/info` | Получить системную информацию (путь к базе) |
| GET | `/api/raw?path=...` | Получить статический файл/картинку из базы |
| POST | `/api/assets` | Загрузить изображение |
| GET/PUT| `/api/config` | Получить/Сохранить настройки |
| POST | `/api/git/sync` | *(В планах)* Запустить синхронизацию с Git |

## CLI-флаги
- `--config` — путь к конфигурации (по умолчанию `~/.config/igonotes`)
- `--port` — порт сервера (по умолчанию `8080`)
- `--base` — имя базы для открытия
- `--no-browser` — не открывать браузер автоматически

Пример:
```bash
igonotes --port 9000 --base work-notes
```

## Работа с Git в проекте

Используется ветвевая модель:
- `develop` — основная ветка разработки.
- `master` — стабильная версия и релизы.
- `pages` — ветка для документации.

## Текущее состояние (что уже сделано)
Проект успешно инициализирован, фронтенд и бэкенд полностью интегрированы:
- **Запуск приложения**: Реализовано автоматическое кроссплатформенное (Windows, macOS, Linux) открытие локального URL в браузере при старте, отключаемое ключом `--no-browser`.
- **Дерево и ФС**: Приложение успешно сканирует папку базы и строит иерархическое дерево через SQLite. Реализовано "умное" ожидание фоновой синхронизации: при старте бэкенд блокирует запрос дерева до окончания индексации, благодаря чему фронтенд всегда получает полные данные. Добавлена кнопка обновления дерева, которая через `POST /api/sync` мгновенно синхронизирует изменения с диска.
- **Интерфейс**: Сверстан общий Layout (разделенный на дерево и редактор) на Tailwind CSS. Добавлен глобальный статус-бар на всю ширину окна внизу экрана для отображения текущего пути к базе заметок. Кнопки управления в дереве заметок оформлены в виде иконок с всплывающими подсказками.
- **Редактор**: CodeMirror 6 с поддержкой Markdown. Реализовано живое превью с интерактивными чекбоксами задач (AST-парсинг), поддержкой YAML Frontmatter (аккуратно скрывается в `<details>`). Добавлена панель инструментов с иконками для форматирования текста (вкл. таблицы с интерактивной сеткой, списки, подчеркивание). Реализованы выпадающие списки для уровней заголовков и вставки блоков кода. Добавлено автодополнение Markdown-команд через `/` и `\`, а также автозакрытие скобок.
- **Подсветка синтаксиса**: Динамическая подсветка блоков кода работает прямо в редакторе (через `@codemirror/language-data`) и в режиме превью (через `highlight.js` с темной темой).
- **Автосохранение**: Работает надежное debounce-сохранение (2 секунды) без перезагрузки интерфейса.
- **Управление**: Полноценные модальные окна (Tailwind UI + requestAnimationFrame автофокус) для создания, удаления и переименования файлов и папок с защитой от конфликтов имён (`409 Conflict`). Добавлено умное модальное окно вставки ссылок с автозаполнением выделенного текста.
- **Медиа и файлы**: Поддерживается загрузка картинок (через Drag&Drop, Paste из буфера обмена или кнопку) с генерацией безопасных имен (с timestamp). Настроена защита от Path Traversal при отдаче статики. Работают Obsidian-стиль ссылки вида `![[image.png]]`.
- **Дальнейшие шаги**: Требуется реализация UI мастера первичной настройки приложения (сохранение конфигурации в файл) и полноценной Git-синхронизации (через `go-git`) в фоновом режиме.
