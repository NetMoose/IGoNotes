# Спецификация API IGoNotes

Данный документ описывает REST-интерфейс, предоставляемый сервером IGoNotes.

## Базовый URL

```
http://localhost:8080/api
```

## 1. Получение дерева заметок

- **Метод**: `GET`
- **Путь**: `/notes`
- **Описание**: Возвращает древовидную структуру всех заметок и папок.
- **Ответ**:
```json
[
  {
    "name": "notes",
    "type": "dir",
    "children": [
      {
        "name": "idea.md",
        "type": "file",
        "path": "notes/idea.md"
      }
    ]
  }
]
```

## 2. Получение содержимого заметки

- **Метод**: `GET`
- **Путь**: `/note?path=ПУТЬ_К_ФАЙЛУ`
- **Параметры**:
  - `path` (string) — путь к файлу, например `notes/idea.md`.
- **Ответ**: Текстовое содержимое файла (Markdown).

## 3. Сохранение заметки

- **Метод**: `POST`
- **Путь**: `/save`
- **Тело запроса** (JSON):
```json
{
  "path": "notes/new.md",
  "content": "# Новая заметка\n\nЭто содержимое..."
}
```
- **Заголовки**:
  - `Content-Type: application/json`
- **Ответ**: `200 OK` при успехе.

## 4. Создание папки (будет реализовано)

Планируется добавить эндпоинт для создания папок.

## Обработка ошибок

- `400 Bad Request` — неверные параметры.
- `404 Not Found` — файл не найден.
- `500 Internal Server Error` — ошибка на стороне сервера.

---

> **Примечание**: Все пути относительны корня проекта. Сервер автоматически управляет структурой каталогов.
