# Руководство пользователя IGoNotes

IGoNotes запускает локальный сервер и открывает редактор Markdown-заметок в браузере.

## Запуск приложения

Установленный бинарник запускается командой `igonotes`. При работе из исходного кода:

```bash
make all
./builds/igonotes
```

Сервер слушает только локальный адрес `http://127.0.0.1:8080`, а браузер открывается автоматически. Если браузер не открылся, перейдите по этому адресу вручную.

Флаги `--config`, `--port`, `--base` и `--no-browser` задают каталог конфигурации, порт, уже настроенную базу для запуска и отключение автоматического открытия браузера.

## Запуск как пользовательский сервис Linux

Только в Linux команда `igonotes service install` создает пользовательский юнит systemd в `$XDG_CONFIG_HOME/systemd/user/igonotes.service`, если `XDG_CONFIG_HOME` задана, иначе в `~/.config/systemd/user/igonotes.service`. Она запускает сервис сразу и включает его для следующих входов пользователя в систему или пользовательских сессий.

```bash
igonotes service install --port 9000 --config /path/to/config --base work-notes
```

Пропущенные параметры используют обычные значения по умолчанию. Повторная установка обновляет юнит и перезапускает сервис. Сервис всегда запускается с `--no-browser`, поэтому обычная вкладка браузера не открывается автоматически.

Юнит хранит абсолютный путь к текущему бинарнику и не копирует его. Разместите бинарник по стабильному пути: после перемещения или удаления `ExecStart` перестанет работать. После смены пути повторите `igonotes service install` из нового расположения.

Для установки не нужны `sudo`, права `root` или системный юнит. User linger автоматически не включается, поэтому сервис не гарантирован до входа пользователя и после завершения его последней сессии.

Диагностика выполняется командами `systemctl --user status igonotes.service` и `journalctl --user-unit igonotes.service`.

Для Chromium PWA установите сервис на стабильном порту, откройте в Chromium точный loopback-адрес, например `http://127.0.0.1:9000`, и установите PWA средствами браузера. Origin PWA включает порт, поэтому после его смены нужно открыть и установить новый origin. Команды сервиса не устанавливают и не запускают Chromium PWA.

Команда `igonotes service uninstall` останавливает и отключает сервис, затем удаляет только принадлежащий IGoNotes пользовательский юнит. Она никогда не удаляет бинарник, конфигурацию, метаданные, базы или заметки.

Команды `igonotes service` не поддерживаются в Windows и macOS; там остаются доступны обычный запуск и `--no-browser`.

## Настройка при первом запуске

При новой или пустой конфигурации появляется обязательный мастер. До его завершения редактор недоступен. Настройка состоит ровно из трех шагов:

1. Выберите создание новой базы или подключение существующей.
2. Укажите имя и каталог. Кнопка `Обзор` открывает системный выбор каталога; если он недоступен, путь можно ввести вручную.
3. Проверьте итоговый путь и завершите настройку.

При создании выбранный каталог является родительским, а новая база создается по пути `<directory>/<name>`. Родительский каталог должен существовать, итоговый путь не должен быть занят.

При подключении укажите точный путь к существующему каталогу. Мастер подключает его на месте и не перемещает и не изменяет его содержимое.

## Интерфейс

- Слева находится дерево папок и заметок с командами создания, переименования, удаления и обновления.
- Справа находится редактор CodeMirror с режимами редактирования и предварительного просмотра.
- Панель инструментов вставляет Markdown-форматирование, ссылки, таблицы, блоки кода и изображения.
- В верхней части редактора доступны индикатор сохранения, кнопка `Сохранить` и шестеренка настроек.
- В строке состояния внизу отображается путь текущей базы.

## Редактирование заметок

Изменения автоматически сохраняются через 2 секунды после последнего ввода. Кнопка `Сохранить` выполняет сохранение немедленно.

Изображения можно добавить кнопкой панели инструментов, вставкой из буфера обмена или перетаскиванием. Они сохраняются в `assets/images/`; предпросмотр поддерживает обычные Markdown-ссылки и `![[image.png]]`.

## Настройки баз

Шестеренка открывает полноэкранные настройки. Без перезапуска можно создать или подключить базу, переименовать ее, изменить путь, переключить активную базу или забыть неактивную.

Изменение настроенного отображаемого имени или пути обновляет только конфигурацию. IGoNotes не перемещает каталог или файлы базы.

Перед переходом в настройки или переключением базы IGoNotes немедленно сохраняет текущую заметку и ожидающие загрузки. Ошибка сохранения блокирует переход, чтобы изменения не потерялись.

Команда `Забыть` удаляет только запись из конфигурации и никогда не удаляет каталог или файлы. Нельзя забыть активную или единственную оставшуюся базу.

Вкладка Git отключена. Git-синхронизация пока не реализована и остается будущей возможностью.

## Хранение данных

- Markdown-файлы остаются в выбранных каталогах баз.
- Изображения хранятся в `<путь-базы>/assets/images/`.
- По умолчанию конфигурация хранится в `<os.UserConfigDir()>/igonotes/config.json`. Флаг `--config <каталог>` переопределяет каталог, и файл хранится в `<каталог>/config.json`.
- Метаданные дерева хранятся в SQLite: `~/.igonotes/metadata.db`.

## Завершение работы

При обычном запуске нажмите `Ctrl+C` в терминале. Закрытие терминала не останавливает пользовательский systemd-сервис: для временной остановки выполните `systemctl --user stop igonotes.service`, а для постоянного отключения и удаления — `igonotes service uninstall`.
