# Руководство пользователя IGoNotes

Добро пожаловать в IGoNotes — современный редактор заметок на базе Markdown с синхронизацией через Git.

## Запуск приложения

1. Откройте терминал.
2. Запустите приложение:
   ```bash
   igonotes --port 8080 --base mynotes
   ```
   Поддерживаемые флаги:
   - `--config` — путь к конфигурации (по умолчанию `~/.config/igonotes`)
   - `--port` — порт сервера (по умолчанию 8080)
   - `--base` — имя базы для открытия
   - `--no-browser` — не открывать браузер автоматически

3. Приложение автоматически откроет браузер с интерфейсом. Если этого не произошло — перейдите по адресу [http://localhost:8080](http://localhost:8080).

## Настройка при первом запуске

Если конфигурация отсутствует:
1. Сервер запускается, но вместо редактора открывается мастер настройки.
2. Мастер позволяет:
   - Создать новую базу или подключить существующую
   - Указать имя базы и путь к ней
   - Настроить Git (URL, автосинхронизация)
3. После завершения мастер сохраняет конфиг в `~/.config/igonotes/config.json` и перенаправляет в основной интерфейс.

## Интерфейс

- **Левая панель** — древовидное отображение базы заметок. Кликните по файлу, чтобы открыть его.
- **Центральная область** — редактор Markdown с переключением между режимами редактирования и предварительного просмотра.
- **Панель инструментов** — вставьте Markdown-теги (заголовки, ссылки, изображения и др.).
- **Верхнее меню**: `Файл`, `Настройки`, `Синхронизация`, `Открыть другую базу`.

## Редактирование заметок

1. Выберите заметку из дерева или создайте новую.
2. Редактируйте текст в редакторе CodeMirror.
3. Система автоматически сохраняет изменения каждые 2 секунды после последнего ввода (debounce).
4. Чтобы вставить ссылку на другую заметку, используйте диалоговое окно выбора.

## Поддерживаемые Markdown-теги

IGoNotes использует парсер `marked.js` и поддерживает:
- Заголовки (`#`, `##` и т.д.)
- Выделение (`*курсив*`, `**жирный**`)
- Списки (`-`, `1.`)
- Ссылки и изображения
- Код (`` `inline code` ``, ``` ```)
- Цитаты (`>`) и многое другое.

## Файловая структура

- Заметки хранятся в `~/.igonotes/bases/<база>/<тема>/notes/...`
- Вспомогательные файлы (картинки, вложения) — в `~/.igonotes/bases/<база>/assets/images/`
- Конфигурация — `~/.config/igonotes/config.json` (XDG-совместимо)
- Метаданные (структура, теги) — `~/.igonotes/metadata.db` (BoltDB)

## Синхронизация через Git

- Каждая база может быть git-репозиторием.
- Поддерживается HTTPS и SSH (ключи из `~/.ssh`)
- Синхронизация выполняется фоновой горутиной по расписанию.
- Ошибки выводятся в лог и отображаются во вкладке `Синхронизация`.

## Завершение работы

Закройте терминал или нажмите `Ctrl+C` для остановки сервера.

---

> **Совет**: Все изменения в заметках сохраняются в файловой системе и могут участвовать в Git-истории.
