# Руководство пользователя IGoNotes

Добро пожаловать в IGoNotes — простой и удобный редактор заметок на базе Markdown.

## Запуск приложения

1. Откройте терминал.
2. Перейдите в директорию проекта:
   ```bash
   cd /path/to/IGoNotes
   ```
3. Запустите сервер:
   ```bash
   go run ./cmd/api
   ```
4. Приложение автоматически откроет браузер с интерфейсом. Если этого не произошло — перейдите по адресу [http://localhost:8080](http://localhost:8080).

## Интерфейс

- **Левая панель** — древовидное отображение заметок. Вы можете кликнуть по файлу, чтобы открыть его.
- **Центральная область** — редактор Markdown.
- **Кнопка "Просмотр"** — переключает режим между редактированием и предварительным просмотром.

## Редактирование заметок

1. Выберите заметку из дерева или создайте новую.
2. Редактируйте текст в поле.
3. Система автоматически сохраняет изменения каждые 2 секунды после последнего ввода.
4. При первом сохранении потребуется указать путь (например, `notes/idea.md`).

## Поддерживаемые Markdown-теги

IGoNotes использует парсер `marked.js`, который поддерживает:

- Заголовки (`#`, `##`, и т.д.)
- Выделение (`*курсив*`, `**жирный**`)
- Списки (`-`, `1.`)
- Ссылки и изображения
- Код (`inline code`, ``` ```)
- Цитаты (`>`) и многое другое.

## Создание новых папок и заметок

Создавайте файлы с любым путём, например:
- `projects/new.md`
- `ideas/meeting_2026.md`

Если папок не существует — они будут созданы автоматически.

## Горячие клавиши

- `Ctrl+S` — в будущем будет добавлено ручное сохранение.

## Завершение работы

Закройте терминал или нажмите `Ctrl+C` для остановки сервера.

---

> **Совет**: Все заметки хранятся в файловой системе в каталогах. Вы можете использовать Git для их версионирования.
