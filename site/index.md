# IGoNotes

> Редактор заметок нового поколения

IGoNotes — это современное приложение для создания и управления заметками в формате Markdown. Оно сочетает в себе простоту использования и мощь локального хранения.

## Особенности

- Локальная работа без Git и удаленного сервера
- Поддержка сложных Markdown-структур и автосохранение
- Древовидная организация заметок и несколько баз
- Локальный REST-сервер и встроенный веб-редактор
- Markdown и изображения в обычных файлах, метаданные в SQLite
- Опциональная двусторонняя Git-синхронизация нескольких устройств

Бэкенд использует Go 1.26+, интерфейс — Svelte 5, Vite 8, Tailwind CSS 4 и CodeMirror 6. Для Git-синхронизации нужен внешний Git 2.28+ с заранее настроенной неинтерактивной авторизацией; обычная локальная работа его не требует.

## Начало работы

Установите IGoNotes и запустите:

```bash
igonotes
```

При первом запуске мастер предложит создать или подключить базу. Браузер открывается автоматически; адрес по умолчанию — `http://127.0.0.1:8080`.
