# Spec Delta

## Purpose

Позволить пользователю Chrome/Chromium сохранять содержимое веб-страниц в виде редактируемых Markdown-черновиков с изображениями и отправлять их в IGoNotes, включая работу при временной недоступности приложения.

## ADDED Requirements

### Requirement: User-initiated capture
Расширение SHALL захватывать основное содержимое текущей HTTP(S)-страницы или явно выбранное пользователем выделение только после действия пользователя и SHALL не изменять исходную страницу.

#### Scenario: Capture article
- **WHEN** пользователь запускает захват статьи на поддерживаемой странице
- **THEN** расширение создаёт черновик из основного содержимого без навигации, рекламы и боковых панелей, насколько позволяет структура страницы
- **AND** исходная страница остаётся неизменной

#### Scenario: Capture selection
- **WHEN** пользователь выбирает режим выделения с непустым выделенным фрагментом в основном документе
- **THEN** в черновик попадает только выделенный фрагмент с его форматированием

#### Scenario: Unsupported or empty input
- **WHEN** открыта служебная страница браузера, PDF, отсутствует нужное выделение или основной текст не извлечён
- **THEN** расширение показывает конкретную причину и не отправляет пустую заметку
- **AND** не подменяет неудачный захват статьи полным DOM страницы без выбора пользователя

### Requirement: Editable portable Markdown
Расширение SHALL предоставлять редактируемые заголовок и Markdown, сохранять URL источника и время захвата и преобразовывать поддерживаемые элементы в переносимый Markdown без исполняемого HTML.

#### Scenario: Preserve common formatting
- **WHEN** захватывается текст с заголовками, абзацами, ссылками, списками, цитатами, таблицами, блоками кода и изображениями
- **THEN** черновик сохраняет эти структуры, абсолютные HTTP(S)-адреса ресурсов и Unicode-текст
- **AND** скрипты, обработчики событий, формы и опасные URL не включаются как исполняемое содержимое

#### Scenario: Edit before import
- **WHEN** пользователь меняет заголовок или Markdown и сохраняет черновик
- **THEN** при повторном открытии и отправке используются последние сохранённые изменения
- **AND** источник и время захвата доступны пользователю

### Requirement: Local image capture with visible failures
Расширение SHALL загружать поддерживаемые изображения, на которые ссылается подготовленный Markdown, сохранять полученные байты с черновиком и явно показывать каждую неудачную загрузку. Внешние ссылки вместо недоступных изображений SHALL требовать отдельного выбора пользователя перед импортом.

#### Scenario: Download images before server availability
- **WHEN** веб-страница доступна, а IGoNotes не запущен
- **THEN** успешно загруженные изображения сохраняются в черновике независимо от IGoNotes
- **AND** последующая отправка не требует повторного открытия исходной страницы для этих изображений

#### Scenario: Denied permission or failed image
- **WHEN** загрузка изображения требует невыданного разрешения, завершается ошибкой или превышает лимит
- **THEN** расширение показывает URL и причину, предлагает повторить загрузку или явно оставить внешнюю ссылку
- **AND** не сообщает о полностью автономной копии при наличии внешних изображений

#### Scenario: Relative images and duplicate references
- **WHEN** одно изображение встречается несколько раз либо имеет относительный URL
- **THEN** адрес разрешается относительно страницы, полученные байты не дублируются без необходимости, а все соответствующие вхождения сохраняются в Markdown

#### Scenario: Decode limits or unsupported animation
- **WHEN** изображение превышает сообщённые сервером лимиты пикселей/кадров либо имеет формат APNG или animated WebP
- **THEN** расширение показывает причину и предлагает исправление или явный выбор внешней ссылки, не называя такую копию полностью автономной

### Requirement: Durable local drafts
Расширение SHALL хранить черновики, выбранное назначение, метаданные и полученные изображения локально в профиле браузера до подтверждённого импорта либо явного удаления. Превышение квоты SHALL сохранять существующие черновики и показывать ошибку.

#### Scenario: Restart browser
- **WHEN** браузер закрывается после подтверждения сохранения черновика
- **THEN** после перезапуска пользователь видит черновик с сохранённым текстом и изображениями

#### Scenario: Interrupted operation
- **WHEN** окно расширения закрывается или фоновый процесс останавливается во время подготовки либо отправки
- **THEN** сохранённые данные остаются доступны, незавершённые этапы обозначаются и могут быть возобновлены пользователем

#### Scenario: Storage full
- **WHEN** очередное сохранение не помещается в доступное хранилище
- **THEN** расширение не удаляет старые черновики автоматически и не сообщает, что новые данные сохранены
- **AND** предоставляет возможность освободить место или скачать Markdown текущего материала

### Requirement: Explicit destination and manual delivery
Расширение SHALL давать выбор базы и существующей папки, видимой в дереве заметок, хранить назначение в черновике и отправлять материал только по явному действию пользователя. Ошибка или неоднозначный результат SHALL сохранять черновик и идентификатор попытки.

#### Scenario: Server offline
- **WHEN** выбранный локальный сервер недоступен при отправке
- **THEN** черновик остаётся в списке с понятной ошибкой и возможностью ручного повтора
- **AND** запуск IGoNotes впоследствии сам по себе не вызывает отправку

#### Scenario: Missing destination
- **WHEN** выбранная база переименована, удалена, перемещена или папка отсутствует
- **THEN** отправка блокируется до обновления и подтверждения назначения пользователем
- **AND** расширение не выбирает текущую базу редактора вместо прежнего назначения

#### Scenario: Confirmed import
- **WHEN** сервер подтверждает импорт или возвращает результат ранее завершённой попытки
- **THEN** расширение показывает базу и путь созданной заметки и только затем освобождает черновик и его изображения

### Requirement: Installable Chromium extension
Расширение SHALL поставляться как самостоятельно собираемое Manifest V3-расширение для настольных Chrome/Chromium с инструкциями установки распакованной сборки и настраиваемым loopback-адресом IGoNotes.

#### Scenario: First installation
- **WHEN** пользователь собирает расширение по документации и загружает его через Load unpacked
- **THEN** доступны подключение, захват и список черновиков без установки отдельного native host

#### Scenario: Scoped page access
- **WHEN** пользователь ещё не запускал захват страницы и не разрешал загрузку изображений с дополнительных сайтов
- **THEN** расширение не требует постоянного доступа к содержимому всех вкладок
