# Spec Delta

## Purpose

Обеспечить управляемое подключение Web Clipper к локальному IGoNotes с ограниченными полномочиями, не открывая существующий API приложения произвольным веб-страницам или расширениям.

## ADDED Requirements

### Requirement: Explicit local authorization
IGoNotes SHALL предоставлять в настройках создание, просмотр статуса и отзыв отдельного подключения Web Clipper. Секрет SHALL показываться только при создании, храниться на сервере в необратимом виде и давать доступ только к API Clipper.

#### Scenario: Create connection
- **WHEN** пользователь после завершения первичной настройки создаёт подключение в локальном UI IGoNotes
- **THEN** получает секрет для ввода в расширении и видит активное подключение в настройках
- **AND** `/api/config`, журналы и последующие запросы статуса не раскрывают секрет

#### Scenario: Revoke connection
- **WHEN** пользователь отзывает подключение
- **THEN** последующие запросы с прежним секретом получают `401 clipper_unauthorized`
- **AND** черновики расширения сохраняются для повторного подключения

#### Scenario: Restart application
- **WHEN** IGoNotes перезапускается с тем же хранилищем метаданных
- **THEN** ранее выданный и не отозванный секрет остаётся действующим

### Requirement: Restricted extension transport
API Clipper SHALL принимать запросы только к loopback-хосту с действующим Bearer-секретом. Переданный Origin SHALL принадлежать расширению Chromium; произвольные веб-origin, `null` и wildcard CORS SHALL не допускаться. Существующие API SHALL сохранять прежнюю same-origin-защиту.

#### Scenario: Authorized extension request
- **WHEN** расширение обращается к API Clipper через настроенный локальный адрес с действующим секретом
- **THEN** запрос допускается, включая необходимый ограниченный preflight для Origin расширения
- **AND** запрос не даёт доступа к чтению заметок, изменению настроек или запуску Git

#### Scenario: Unauthorized website or remote host
- **WHEN** запрос содержит веб-Origin, нелокальный Host либо не содержит действующего секрета
- **THEN** сервер отклоняет запрос до раскрытия списка баз и до изменения файлов

#### Scenario: Existing API remains guarded
- **WHEN** расширение с секретом Clipper вызывает `/api/save` или `/api/config` с extension Origin
- **THEN** действуют прежние ограничения origin; секрет Clipper не обходит их

### Requirement: Minimal destination discovery
Авторизованный API Clipper SHALL возвращать версию протокола, возможности и лимиты, имена настроенных баз и существующие папки выбранной базы, видимые в дереве заметок, без содержимого заметок, абсолютных путей и Git-секретов. Назначение SHALL включать непрозрачную ревизию, изменяющуюся при изменении привязки базы.

#### Scenario: Select inactive base
- **WHEN** расширение запрашивает папки настроенной, но неактивной базы
- **THEN** получает папки этой базы и ревизию назначения
- **AND** текущая база редактора остаётся прежней

#### Scenario: Detect changed base binding
- **WHEN** между выбором назначения и импортом меняется имя, путь или идентичность корня базы
- **THEN** прежняя ревизия назначения отклоняется с `409 clipper_destination_changed`
- **AND** расширение требует повторного выбора назначения

#### Scenario: Exclude invisible note destinations
- **WHEN** база содержит `.hidden/`, `assets/`, `nested/.hidden/` или `nested/ASSETS/`
- **THEN** discovery не предлагает эти папки и их потомков как назначения заметки
- **AND** корень базы и обычные видимые вложенные папки остаются доступны

#### Scenario: Setup or protocol mismatch
- **WHEN** первичная настройка не завершена либо версия протокола несовместима
- **THEN** расширение показывает необходимость настройки либо обновления и не отправляет импорт

### Requirement: Local endpoint configuration and secret isolation
Расширение SHALL позволять настройку HTTP loopback-адреса и порта сервера, хранить секрет только в локальном хранилище расширения и не передавать его в DOM страницы, content script, браузерную синхронизацию или URL.

#### Scenario: Non-default port
- **WHEN** пользователь настраивает `http://127.0.0.1:9000`
- **THEN** проверка подключения и импорт используют этот адрес после выдачи необходимых разрешений браузера

#### Scenario: Invalid endpoint
- **WHEN** пользователь вводит адрес удалённого хоста, URL с credentials или адрес с query/fragment
- **THEN** расширение отклоняет настройку до сетевого запроса с секретом

#### Scenario: Untrusted page message
- **WHEN** открытая страница пытается получить секрет или инициировать произвольный запрос через сообщения
- **THEN** расширение не раскрывает секрет и не предоставляет сетевой прокси странице
