# Proposal

## Why

IGoNotes умеет редактировать локальные Markdown-заметки, но сохранение материалов из браузера требует ручного копирования и загрузки изображений. Web Clipper позволит превратить статью или выделенный фрагмент в переносимую заметку с локальными изображениями и не потерять материал, когда приложение не запущено.

## What Changes

- Добавить расширение Manifest V3 для настольных Chrome/Chromium: захват основного содержимого страницы или выделения, преобразование в Markdown, редактирование заголовка и текста, ссылка на источник и время захвата.
- Дать пользователю выбор настроенной базы и существующей папки, видимой в дереве заметок, без переключения базы в открытом редакторе. Скрытые каталоги и `assets` на любом уровне не являются назначениями заметок; изображения по-прежнему сохраняются в `assets/images/`.
- Скачивать изображения в расширении, хранить их вместе с черновиком и импортировать в `assets/images/`; переписывать Markdown-ссылки на локальные пути. Показывать ошибки отдельных изображений и разрешать внешние ссылки только после явного выбора пользователя.
- Поддержать в превью редактора изображения по путям относительно вложенной заметки, сохранив существующие base-root `assets/images/...` и wiki-ссылки.
- Хранить черновики и полученные изображения локально в браузере при недоступном IGoNotes; предоставлять список, редактирование, удаление и ручную повторную отправку после перезапуска браузера.
- Добавить ограниченный локальный API подключения и импорта с отзываемым токеном, явной адресацией базы, защитой от перезаписи и идемпотентным повтором после потери ответа.
- **BREAKING**: проверять глобальную границу служебного хранения при запуске и изменении баз. Базы не могут содержать SQLite, каталог конфигурации или приватный staging; уже пересекающаяся конфигурация требует ручного исправления без автоматического перемещения данных. Штатная база `~/.igonotes/bases/default` остаётся допустимой.
- Добавить управление подключением Web Clipper в настройках IGoNotes, инструкции установки распакованного расширения, независимую сборку и проверки расширения.
- Первая версия не включает публикацию в магазине, Firefox/Safari, Native Messaging, удалённый сервер, автоматический запуск IGoNotes, PDF, архивирование видео/iframe, шаблоны сайтов, AI и автоматическую фоновую отправку черновиков.

## Capabilities

### New Capabilities

- `web-clipping`: захват страницы/выделения, преобразование в Markdown и управление локальными черновиками с изображениями в расширении.
- `clipper-connection`: локальное подключение расширения, выдача и отзыв полномочий, ограниченный доступ к назначениям импорта.
- `clip-import`: адресный, идемпотентный импорт новой заметки и изображений в настроенную базу с сохранением ограничений файловой системы и Git.
- `private-storage-boundaries`: глобальное исключение служебных файлов и приватных каталогов из корней баз при запуске и изменении конфигурации.

### Modified Capabilities

Нет: в текущем OpenSpec отсутствуют основные спецификации. Защита служебных путей добавляет проверку допустимости путей в существующие startup/setup/base/config операции.

## Impact

- Новый самостоятельный frontend-пакет `extensions/webclipper/` с lockfile, сборкой MV3, тестовыми HTML-страницами и упаковываемым `dist/`; он не встраивается в Go-бинарник.
- Предлагаемые зависимости: Mozilla Readability для статьи, Turndown с GFM-правилами для Markdown; весь код расширения поставляется локально, без CDN. DOM страницы не рендерится как доверенный HTML.
- Backend: новые обработчики и сервисы подключения/импорта, миграции SQLite для полномочий и журнала импорта, интеграция в `cmd/api/main.go`. Существующие `RequireLocalOrigin`, порядок блокировок и Git conflict gate сохраняются.
- Web UI: раздел Web Clipper в `web/src/lib/settings/`, управление токеном без раскрытия его через `/api/config`.
- Preview: точечная корректировка image path resolution и экранирования отображаемого frontmatter в `web/src/lib/Editor.svelte` для переносимых импортированных заметок.
- Документация: `docs/user.md`, `docs/api.md`, `docs/developer.md` и точные зеркала `site/docs/`; CI/Makefile дополняются проверками отдельного пакета.
- Предположение первой поставки: локальный HTTP loopback-сервер на том же компьютере (по умолчанию `127.0.0.1:8080`, порт настраивается), установка расширения через Load unpacked; пользователь подтверждённо выбрал объём с изображениями и офлайн-черновиками.
