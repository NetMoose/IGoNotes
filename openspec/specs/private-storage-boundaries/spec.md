# private-storage-boundaries Specification

## Purpose

Отделить пользовательские базы заметок от конфигурации, SQLite и приватных временных данных приложения, включая изменения настроек во время импорта из браузера.

## Requirements

### Requirement: Global private-storage exclusion
IGoNotes SHALL запрещать корни баз, включающие служебную SQLite, её служебные файлы, каталог конфигурации либо приватный staging. Базы SHALL также не находиться внутри зарезервированных приватных каталогов. Проверка SHALL учитывать канонические пути и aliases, сохраняя допустимость штатной базы `~/.igonotes/bases/default`.

#### Scenario: Overlapping base root
- **WHEN** пользователь подключает базу, содержащую конфигурацию, SQLite или приватный staging, либо находящуюся внутри приватного каталога
- **THEN** API отвечает `422 invalid_base_path` без изменения прежней конфигурации и пользовательских файлов

#### Scenario: Default base remains supported
- **WHEN** приложение использует штатную базу `~/.igonotes/bases/default` при штатных путях служебного хранения
- **THEN** база проходит проверку, хотя находится под общим каталогом данных приложения

#### Scenario: Alias and not-yet-created private path
- **WHEN** пересечение проходит через символическую ссылку или существующий предок ещё не созданного служебного каталога
- **THEN** проверка обнаруживает пересечение до создания базы или приёма приватных данных

### Requirement: Lifecycle-wide enforcement
IGoNotes SHALL проверять все настроенные базы при startup и до успешного setup, добавления, изменения, замены конфигурации и переключения базы. Изменение путей во время upload SHALL не позволять объявить приватный staging частью базы.

#### Scenario: Configuration change during upload
- **WHEN** идёт приём клипа и параллельно поступает конфигурация с базой, пересекающей приватный staging
- **THEN** изменение отклоняется, а сетевое чтение не удерживает глобальные блокировки lifecycle

#### Scenario: Existing incompatible configuration
- **WHEN** при запуске найдена пересекающаяся настроенная база, включая неактивную
- **THEN** приложение сообщает о несовместимом пути и не открывает сервер с такой конфигурацией
- **AND** не перемещает и не удаляет файлы автоматически; пользователь может исправить конфигурацию вручную
