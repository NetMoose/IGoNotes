# IGoNotes — Редактор заметок на Go и Markdown

IGoNotes — это CLI-приложение на Go, которое запускает локальный REST-сервер и открывает в браузере веб-интерфейс для редактирования Markdown-заметок. Проект поддерживает древовидную структуру каталогов, редактирование и предварительный просмотр Markdown с поддержкой современных спецификаций.

## Особенности

- Локальный REST-сервер и встроенный веб-интерфейс, открываемый в браузере
- Редактор Markdown с подсветкой синтаксиса, панелью форматирования и предпросмотром
- Дерево заметок: создание, переименование и удаление папок и файлов
- Автосохранение, вставка и загрузка изображений
- Несколько локальных баз с настройками и переключением без перезапуска
- SQLite для метаданных; Markdown и изображения остаются обычными файлами
- Опциональная двусторонняя Git-синхронизация нескольких устройств с явным разрешением конфликтов

## Технологии

- **Бэкенд**: Go (1.26+), `net/http`
- **Фронтенд**: Svelte 5, Vite 8, Tailwind CSS 4, CodeMirror 6, marked.js
- **Хранение**: Markdown-файлы и SQLite (`modernc.org/sqlite`)
- **Git**: внешний системный Git 2.28+; необязателен для локальной работы
- **Сборка и релиз**: GitHub Actions

## Начало работы

Для сборки из исходного кода нужны Go 1.26+, Node.js 24, npm и GNU Make. `make all` устанавливает frontend-зависимости по lockfile, собирает интерфейс и встраивает его в бинарник.

```bash
# Полная сборка frontend и backend
make all

# Запуск собранного приложения
./builds/igonotes
```

Сервер слушает `http://127.0.0.1:8080`, браузер открывается автоматически. При первом запуске мастер предложит создать или подключить базу. Для установленного в PATH бинарника команда запуска — `igonotes`.

Проверки из корня проекта:

```bash
# Frontend-тесты и сборка, Go-тесты, race detector и go vet
make verify

# Обязательные интеграционные проверки с реальным системным Git
make test-git
```

`make test-git` требует Git 2.28+ и включает обязательный режим Git-интеграционных тестов.

## Git-синхронизация

Git необязателен для обычных локальных баз. Для синхронизации нужен системный Git 2.28 или новее, заранее настроенная неинтерактивная авторизация через SSH-agent, credential helper или Git config и Git identity (`user.name`, `user.email`). IGoNotes не хранит HTTPS-токены и SSH-ключи и не запрашивает пароль в терминале.

Интеграция настраивается отдельно для каждой базы: `origin`, ветка, ручной режим или автоматический интервал 5/15/30/60 минут (по умолчанию 15) и шаблон сообщения коммита. Sync фиксирует все неигнорируемые файлы базы через `git add -A`, получает удаленные изменения, выполняет обычное слияние и push без rebase или force-push. Конфликты разрешаются явно в интерфейсе. После пяти последовательных операционных ошибок синхронизация приостанавливается до явного возобновления.

Подключение, работа с двумя устройствами, статусы, конфликты и отключение описаны в [руководстве пользователя](docs/user.md#git-синхронизация).
