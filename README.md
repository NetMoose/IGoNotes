# IGoNotes — Редактор заметок на Go и Markdown

IGoNotes — это CLI-приложение на Go, которое запускает локальный REST-сервер и открывает в браузере веб-интерфейс для редактирования Markdown-заметок. Проект поддерживает древовидную структуру каталогов, редактирование и предварительный просмотр Markdown с поддержкой современных спецификаций.

## Особенности

- REST-сервер на Go
- Веб-интерфейс с редактором Markdown и просмотром результата
- Древовидное отображение заметок
- Поддержка создания папок и файлов
- Автосохранение
- Использование встраиваемой БД (планируется BoltDB)

## Технологии

- **Бэкенд**: Go (1.21+)
- **Фронтенд**: HTML, CSS, JavaScript (marked.js для парсинга Markdown)
- **Хранение**: BoltDB (планируется)
- **Сборка и релиз**: GitHub Actions

## Начало работы

```bash
# Клонирование
# Убедитесь, что вы находитесь в ветке develop

go mod tidy

go run ./cmd/api
```

Сервер запустится на `http://localhost:8080`.

## Ветки

- `develop` — основная ветка разработки
- `master` — стабильная версия для релизов
- `pages` — ветка для сайта документации (Jekyll)
