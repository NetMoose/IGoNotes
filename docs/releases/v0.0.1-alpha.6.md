# v0.0.1-alpha.6

## Что нового

- В настройках появилась вкладка **«О программе»** с названием IGoNotes и версией запущенного приложения.
- Версия релизной сборки автоматически берётся из тега; локальные сборки без заданной версии обозначаются как **«Сборка разработки»**.
- Кнопка **«Настройки»** перенесена в левую панель — последней в ряд кнопок над деревом заметок.

## Улучшения

- Раздел «О программе» поддерживает загрузку данных, отображение ошибки и повторный запрос.
- Клавиатурная навигация настроек охватывает все три вкладки, включая «О программе».
- Перед переходом в настройки приложение по-прежнему дожидается загрузки изображений и сохраняет текущую заметку. Ошибка сохранения блокирует переход.
- API `GET /api/info` дополнен строковыми полями `app_name` и `app_version`; поле `base_path` сохраняется.
- Обновлены пользовательская документация, описание API и руководство разработчика.

## Загрузки

Архивы для Linux, Windows и macOS доступны в вариантах **amd64** и **arm64**. SHA-256 каждого архива указан в `checksums.txt`.

Для Git-синхронизации требуется системный Git 2.28+. Локальные базы работают без установленного Git.
