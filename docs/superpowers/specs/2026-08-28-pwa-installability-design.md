# Устанавливаемый веб-интерфейс IGoNotes

## Цель

Сделать страницу IGoNotes устанавливаемой как приложение в настольных Chromium-браузерах. Браузер должен распознавать страницу как PWA, показывать штатный элемент установки и после установки открывать интерфейс в отдельном окне без обычных панелей браузера.

Установка относится только к веб-интерфейсу. Она не запускает Go-бинарник: локальный сервер IGoNotes должен уже работать на том же адресе и порту.

## Область поддержки

Основная среда — Chrome, Edge и другие Chromium-браузеры на настольных ОС. Приложение открывается с loopback-адреса `http://127.0.0.1:8080`, который допускается браузерами для установки без HTTPS.

Установка привязана к origin, включая порт. Изменение `--port` после установки создаёт другой origin, а прежний ярлык продолжает открывать исходный порт.

Браузер сам выбирает момент показа установки. Manifest делает приложение доступным для штатной установки, но не гарантирует немедленный автоматический диалог.

## Web App Manifest

В `web/public/manifest.webmanifest` должен находиться manifest со следующими свойствами:

- `id: "/"`;
- `name: "IGoNotes"`;
- `short_name: "IGoNotes"`;
- `start_url: "/"`;
- `scope: "/"`;
- `display: "standalone"`;
- `theme_color: "#2563eb"`;
- `background_color: "#f1f5f9"`;
- `prefer_related_applications: false`;
- `icons/icon-192.png` размером `192x192` с `purpose: "any"`;
- `icons/icon-512.png` размером `512x512` с `purpose: "any"`;
- `icons/icon-maskable-512.png` размером `512x512` с `purpose: "maskable"`.

`web/index.html` должен ссылаться на manifest и новый favicon, задавать `theme-color` и использовать `lang="ru"`.

## Иконка

Иконка использует утверждённый вариант C: синюю монограмму `IG` в светлом контуре страницы. Основной фон — `#2563eb`; белые и светло-синие линии соответствуют текущей палитре интерфейса.

Знак должен иметь безопасные поля, чтобы сохранять читаемость после системной обрезки. `web/public/favicon.svg` содержит исходный векторный знак и служит favicon. В `web/public/icons/` должны храниться готовые PNG-файлы, чтобы устанавливаемость не зависела от поддержки SVG-иконок браузером.

Текущий фиолетовый favicon Vite заменяется новым знаком IGoNotes.

## Сборка и раздача

Vite копирует manifest и иконки из `web/public/` в `web/dist/`. Существующий `//go:embed all:dist` включает их в бинарник, а `SPAHandler` раздаёт их как статические файлы.

Backend API, модели данных и пользовательские заметки не меняются. Ответ для `/manifest.webmanifest` должен иметь `Content-Type: application/manifest+json`; существующую реализацию `SPAHandler` следует менять только в том случае, если стандартный `http.FileServer` не выполняет это требование.

## Не входит в изменение

- Service worker и offline-режим.
- Кеширование frontend или ответов API.
- Собственная кнопка установки и обработчик `beforeinstallprompt`.
- Запуск Go-бинарника из установленного ярлыка.
- Публикация приложения в магазинах.

## Проверка

- Автоматически проверить обязательные поля manifest и ссылки на него и favicon в `index.html`.
- Проверить наличие и реальные размеры PNG-иконок.
- Собрать frontend командой `npm run build` и убедиться, что manifest и иконки попали в `web/dist/`.
- Запустить frontend-тесты командой `npm test`.
- Запустить Go-тесты и проверить раздачу manifest и иконок через `SPAHandler`, включая статус, содержимое и тип содержимого manifest.
- Запустить встроенный сервер на `127.0.0.1:8080` и проверить в Chromium DevTools раздел Application: manifest распознан без ошибок, обе обязательные иконки доступны, режим отображения — standalone.
- Установить IGoNotes штатным элементом Chromium и убедиться, что ярлык открывает отдельное окно при уже запущенном Go-сервере.
